# Roadmap

## Now (shipped)

Site, auth, trial, dashboard, buddy gallery, custom buddy, permissions, memory,
MV3 extension with page understanding, voice, explain + highlight, task tracing,
provider-agnostic AI orchestrator with fallback, diagnostics.

## Next

1. **Browser agent (phase 4)** — click / type / select / scroll with pre-action
   re-resolution, post-action verification and bounded recovery. Gated by permission
   level `assist` / `execute` and per-action confirmation.
2. **Form engine (phase 5)** — field understanding, ask-when-unknown, reusable
   templates, validation reading.
3. **Skills + workflows (phase 6)** — skill registry, tool registry with risk levels,
   multi-step task state, approval before high-impact submission; specialist packs for
   e-commerce, CA, legal and developer work.
4. **Memory + teach & replay (phase 7)** — promote durable preferences from
   conversation, record an approved workflow, replay by re-identifying elements.
5. **Self-debug and bug autopilot (phase 8)** — failure classification, root-cause
   report, safe recovery attempt, automated regression run.
6. **Emotion + 3D buddy (phase 9)** — richer animation set and graphics modes.
7. **Cross-check and discovery (phase 10)** — multi-model verification for
   high-stakes answers, daily tool/model discovery with a propose→evaluate→approve
   pipeline (never auto-installing code).

## Deliberately out of scope

Wake-word always-on listening (browser and privacy constraints), bypassing CAPTCHA or
payment confirmations, access to `chrome://` pages, and anything requiring a native
host binary.
